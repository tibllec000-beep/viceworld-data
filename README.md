# viceworld-data

Conteúdo do app **Vice World – Mundo Vice** (fã, não oficial).
O app lê os arquivos de `data/`:

- `catalog_LANG.json`, `wiki_LANG.json` – vídeos e wiki (atualizados pelo robô em `robot/`)
- `wallpapers.json` + `wallpapers/` – wallpapers da aba Wallpapers
- `missions_LANG.json` – missões da aba Missões (cai para `missions_en.json`)
